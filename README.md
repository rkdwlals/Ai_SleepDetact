# AI 졸음 방지 시스템 (Ai_SleepDetact)

웹캠으로 눈 감김을 감지해, 졸고 있으면 경고음을 울리고 카카오톡으로 알림을 보내는 프로그램입니다.
학술제에서 발표했습니다.

- 시기: 2023년 10월~12월
- 언어·라이브러리: Python, OpenCV, MediaPipe Face Mesh, beepy, 카카오톡 메시지 API

## 동작

1. OpenCV로 웹캠 프레임을 받아 MediaPipe Face Mesh로 얼굴 랜드마크를 찾습니다.
2. 왼쪽 눈 위·아래(159번, 145번)와 오른쪽 눈 위·아래(386번, 374번) 랜드마크 사이 거리를 계산합니다.
3. 눈 사이 거리가 기준값보다 작은 상태가 30번 연속(프레임마다 200ms 대기) 이어지면 졸고 있다고 판단합니다.
   현재 코드는 판정에 왼쪽 눈 거리만 사용합니다.
4. 졸음으로 판단되면 경고음을 울리고, 카카오톡 "나에게 보내기"로 경고 메시지와 잠 깨는 노래 링크를 보낸 뒤 종료합니다.

## 파일

| 파일 | 내용 |

| `발표 자료.pptx` | 학술제 발표 자료 |

## 실행

```bash
pip install opencv-python mediapipe beepy requests
python "미디어 파이프 얼굴 좌표(최종판).py"
```

카카오톡 알림을 쓰려면 Kakao Developers 앱 키와 `kakao_token.json`이 필요합니다. `Sound.py`에 남아 있는 앱 키는 더 이상 사용하지 않는 키입니다.
